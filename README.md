
# Moe's Auto Parts

This is a Moe's Auto Parts web application powered by using Java Spring Boot on the 
backend while Thymeleaf HTML and CSS handles the frontend using SSR. This project allows users to add autoparts for their vehicles to purchase just like a standard auto parts store. They will place an online order for your vehicle needing a specific auto part like a transmission, tire, wheel, engine, brakes, etc... You can add or delete them. You can also just search for existing parts presently in the system. It's an interactive web application built to simulate what users need from an auto parts store.

## Run Locally

Clone the project

```bash
  git clone https://github.com/VkProjects907/Auto-Parts.git
```

Go to the project directory

```bash
  cd d287-java-frameworks-master
```

Install dependencies

```bash
  mvn clean install
```

Start the server

```bash
  mvn spring-boot:run
```
